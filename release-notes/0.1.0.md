## KeyFlag 0.1.0

The first release. KeyFlag brings back the keyboard layout flags from classic Mac OS X: the current layout's country flag in the menu bar, in the layout menu, and next to the pointer whenever it's over a text field.

Requires macOS 13 Ventura or later. Signed with Developer ID and notarized by Apple.

### Install

Download **KeyFlag-0.1.0.zip** below, unzip it, move **KeyFlag.app** to Applications and open it. When asked, turn on KeyFlag in **System Settings → Privacy & Security → Accessibility**.

Or with Homebrew:

```bash
brew install --cask kurtcz/tap/keyflag
```

### Features

- **Flags:** Classic (drawn in the old Mac OS X style, with Wikimedia Commons artwork for flags with emblems or fine detail; the rest fall back to emoji), Emoji, Waving (the classic flags, animated), Coat of Arms (the shield from 87 countries', regions' and historical states' arms), or Off for macOS's own icons. Input methods keep their own icons.
- **Flag for each layout:** pick any flag for a layout, including regional ones (Quebec, the home nations, Kurdistan…), old monarchies and historical states (Bohemia, Prussia, the USSR…). The Welsh layout shows the Wales flag.
- **Indicator next to the pointer** over text fields. It fades in and out, hides while you type, scroll or drag, and comes back when you move the pointer or switch layouts. It sits beside the cursor and flips at screen edges.
- **Optional extras, off by default:** remember the layout for each app, show the indicator next to the text caret, and flash a large flag when the layout changes.
- **Caps Lock:** a ⇪ badge next to the indicator and the menu bar icon while Caps Lock is on.
- **Menu bar:** show the layout alone or with its name, and switch layouts from the menu.
- **Options:** smaller indicator, tint for see-through icons (gray, red, green, blue), and launch at login.
- **Shortcuts:** Keyboard Settings, Keyboard Viewer, and Emoji & Symbols, including a fix for Emoji & Symbols on macOS 26 Tahoe.
- **Automatic updates** through Sparkle, plus **Check for Updates…** in the menu.

### Notes

- If KeyFlag can't get the icon for an input source, it shows a letter badge instead. It then warns you once, with a link to report the input source.
- No analytics, crash reporting or hardware identifiers.

### Fixed since the first upload

- The zip was repacked so it opens correctly with any unzip tool. The first upload contained hidden `._` files that unzippers other than Finder's put inside the app. That broke the signature, and macOS said it "could not verify" KeyFlag. If you got that message, download again, or run `dot_clean -m /Applications/KeyFlag.app`.
- Rebuilt with per-app layouts, the caret indicator, the layout flash, flags for each layout and the Coat of Arms style. KeyFlag's own updater offers the new build to existing installs.
- The menu bar icon, the layout flash and the pointer indicator no longer sometimes show the previous layout after a switch. They now always match the caret indicator.
- With Flags set to Off, Apple's keyboard layouts now show the same labels as macOS's own Input menu (ف• for Persian, РУ for Russian, A for a single Latin layout) instead of a country code. Unicode Hex Input no longer shows an empty badge.
